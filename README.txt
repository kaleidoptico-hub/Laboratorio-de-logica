# Kaleidóptico 360.º — Laboratório de Lógica

Atividade interativa de tabelas de verdade para Filosofia, 10.º ano.

## Conteúdo
- Explicação dos operadores: negação, conjunção, disjunção inclusiva, condicional e bicondicional.
- Tabelas de referência.
- Treino com feedback e explicações.
- Construção de tabelas de duas e três variáveis, incluindo colunas intermédias.
- Avaliação final de 10 questões, com classificação sobre 100 pontos e correção comentada.

## Publicar na Vercel (sem instalar programas)
1. Descompacta `kaleidoptico-laboratorio-logica.zip`.
2. Cria um repositório no GitHub e carrega para lá os ficheiros `index.html` e `vercel.json`.
3. Na Vercel, escolhe **Add New → Project** e liga o repositório GitHub.
4. Em Framework Preset, seleciona **Other**. Não é necessário Build Command nem Output Directory.
5. Carrega em **Deploy**. A Vercel publica a atividade e atribui-lhe um endereço `.vercel.app`.

## Nota
A atividade funciona no navegador e não necessita de base de dados. As respostas e pontuações não são enviadas nem guardadas num servidor. Cada aluno pode utilizar a atividade sem criar conta.
